像素村庄素材包 · 静态第一版

内容
- background.png：480×320 不透明草地背景，建议以 960×640（2 倍）显示。
- buildings/：5 张独立 64×64 透明 PNG。
  square.png：首页入口/广场；mindfulness.png：正念亭子；
  fitness.png：哑铃标识健身小屋；todos.png：待办公告栏；
  settings.png：齿轮与工具标识设置小屋。
- roads/：11 张 32×32 透明道路 PNG，路口宽度统一为 12 像素。
  straight-ew：东西直路；straight-ns：南北直路；cross：十字路。
  corner-0：西→南，编号 1/2/3 顺时针旋转 90/180/270 度。
  tee-0：西、东、南三向，编号 1/2/3 顺时针旋转。
- decorations/：16 张 64×64 透明 PNG，含树、花、石头、围栏、备用建筑等。
- preview/：组合预览与道路预览，仅供参考，不用作独立素材。
- layout-example.json：桌面组合示例，各坐标使用原始 480×320 画布单位。
- manifest.json：每张独立素材的尺寸及透明通道检查结果。
- source/：4 张生成原图；均为扁平 PNG，不是分层绘画工程文件。

画风与来源
功能建筑采用正面略俯视的 RPG 像素视角，道路与地面采用俯视投影。
主要光源来自左上。上传的原始 64×64 图保持原样；背景、健身及设置小屋
用内置图像生成工具制作，道路由生成道路图裁切、旋转和组合。
新小屋以近邻采样整理到 64×64，与原素材保持接近的像素尺度。
各元素独立提供，未把功能建筑或道路绘制进背景。

网页接入
1. CSS 设置 image-rendering: pixelated，使用 1×/2×/3×整数倍显示。
2. 位置以元素底部中心为锚点（bottom-center）。房屋和公告栏点击区由代码定义。
3. 示例上方安全区为 x=80,y=8,w=320,h=64；时间、日期、天气由网页绘制。
4. 手机端重新安排建筑与道路位置，不建议把整个桌面画布非整数缩小。
5. 叠放顺序：背景 → 道路 → 广场 → 建筑/装饰 → 网页界面。
6. 道路按 32 像素网格拼接；不要独立进行非整数缩放，以免产生接缝。
7. 建筑缩略图和地形采用不同常规游戏投影，组合预览只示意布局，不代表实际比例。

动画与阴影
本版全部为静态素材，未附动画、独立阴影层或 PSD/Aseprite 工程文件。
已有素材内的局部明暗保留。悬停高亮、点击反馈、天气效果由代码处理。
