# 像素生活村庄

入口仍为 `/admin.html`，需要独立账号和密码，主账号为 `owner`。升级多账户须先应用 `0004_accounts.sql`，见 [多账户说明](accounts.md)。公开博客 `/` 不变。

## 五个栏目

- **首页**：静态像素村庄，五座建筑直接进入对应页面；显示浏览器本地时间、城市天气、今日未完成数量和最近一句正念。
- **正念**：正文必填，出处选填；Enter 保存、Shift+Enter 换行。支持编辑、删除和本页撤销。编辑不会改变原记录日期。
- **健身**：胸、腿、肩、背、有氧五个像素小按钮。力量训练填写动作、重量（kg）、组数（1–50）以及每组次数；有氧填写类型、时间（min），速度（m/s）、坡度（%）、长度（km）选填。五类均可写心得、选择日期补记。同一天集中在一个紧凑卡片中，按记录时间逐行追加；日期倒序、分批加载，保留编辑、删除、撤销和分类草稿。旧版记录继续显示并可编辑。新增指标存入现有 details 字段，无需新增迁移。
- **待办**：新增默认归到今天；之前未完成、之后安排和已完成分别折叠，旧任务可移到今天。支持勾选、修改、删除与本页撤销。
- **设置**：天气城市、外观、桌宠显示/音效、数据导出、退出登录。笔记、文档、习惯与公开博客在“更多入口”中。

正念/健身存入 D1，不是仅保存在浏览器。城市、天气缓存、外观与声音偏好保存在当前浏览器。未保存的正念/健身输入在同一页面会话的栏目切换之间保留；刷新或关闭页面不会保留未提交的输入。删除正念/健身采用软删除，列表和导出均排除已删除项；本页撤销可恢复原 ID。

## 上线前必须执行一次新增表迁移

此重构没有执行远端迁移或部署。在部署新版 Worker **之前**执行：

```sh
npm run db:life:remote
npm run deploy
```

第一条只执行 `migrations/0003_life_entries.sql`：新建生活记录表和索引，可重复执行，不改动旧笔记、待办、习惯或文档，也不会重新插入示例数据。若使用 Cloudflare Git 自动部署，也请在新版部署前完成此命令。不要删除/重建原 D1 或 R2。

本地 `npm run dev` 会自动应用新增迁移，不需要额外操作。

## 天气

使用 Open-Meteo 的城市查询与当前天气，通过受登录保护的 Worker 接口请求固定上游地址。城市查询至少两个字符，可用中文或拼音；不申请浏览器定位权限。当前天气在浏览器缓存 30 分钟，上游请求设置 7 秒超时；天气失败仅显示“天气暂不可用”，不会阻塞首页。

上线环境需要能访问 `geocoding-api.open-meteo.com` 和 `api.open-meteo.com`。当前开发云环境到 Open-Meteo 的代理连接返回 403，因此这里验证的是接口映射、缓存流程、受控失败降级和模拟天气浏览器交互，未宣称真实天气上游已连通。实际连通性需在部署环境确认。数据来源链接保留在设置页。

## 素材与性能

素材来自用户上传的 `village-assets.zip`，原样使用独立 PNG。来源说明与原素材清单保留在 `public/village/README.txt`、`manifest.json`。生成原图和预览图不部署。

场景约 316 KB（包含备用素材），使用 HTML 链接和像素图片，没有 Canvas 游戏循环、角色寻路、建造或升级系统。私人空间不启动星空动画；时钟每 30 秒检查一次，离开首页清理计时器。桌宠沿用已有动画与收起功能，所有点击动作统一使用 jump.mp3；音效开关只放在设置页，不恢复悬浮静音按钮，其资源体积不包含在村庄素材体积内。手机重新排列建筑，原图 64px 按 2 倍显示，文字标签和底部导航均可进入功能。

## 验证

```sh
npm run test:all
npm run build
npm run dev
BASE_URL=http://127.0.0.1:8787 PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs node tools/test-village-browser.mjs
```

浏览器测试使用当前本地登录配置，仅新建带测试标识的记录，结束时删除本次记录；软删除的测试记录仍保留在本地 SQLite 中。API 测试使用临时数据库，覆盖持久化、分页、校验、认证、删除撤销、导出和天气降级。不要针对生产站点运行浏览器写入测试。

## v2 功能面板

以用户上传的 `village-assets-v2.zip` 四张面板为边框风格参考：正念采用卷轴暖色、健身采用银紫色、待办采用木色、设置采用金色。原图和来源说明保留在 `public/village/panels/`，页面使用 `public/panel-layout.css` 绘制轻量像素边框，不再放大整张图片。

卡片宽度随页面、高度随内容，使用整页滚动，取消固定正方形和框内滚动。正文至少 16px，正念桌面 18px、手机 17px，辅助文字至少 13px；内容沿用日夜主题的纯色背景和文字配色。输入表单保持在框外，村庄建筑素材未变。
